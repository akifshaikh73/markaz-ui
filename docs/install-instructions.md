# Install Chicago Visitations

Chicago Visitations is a web app that can be installed on supported browsers as a Progressive Web App (PWA). Installation creates an app icon and opens the app in its own window. The app normally starts at the masjid login screen.

Use the production URL supplied by your organization. The install option is normally available only when the site is served over HTTPS. A local development URL such as `localhost` may behave differently.

## Before you start

- Make sure you have the correct Chicago Visitations URL.
- Use a current version of Chrome, Safari, Edge, or another supported browser.
- Keep your masjid PIN, or your administrator email and PIN, available.
- Do not save credentials on a shared device.

## Android: install with Chrome

1. Open the Chicago Visitations URL in Chrome.
2. Wait for the login page to finish loading.
3. Open the Chrome menu using the three dots in the upper-right corner.
4. Choose **Install app** or **Add to Home screen**.
5. Confirm with **Install** or **Add**.
6. Open the new Chicago Visitations icon from your Home screen or app drawer.

If Chrome shows an install banner or an install icon in the address bar, either option can be used. The wording varies by Android version and Chrome release.

### Android fallback: bookmark or Home screen shortcut

If **Install app** is not available:

1. Open the site in Chrome.
2. Open the three-dot menu.
3. Choose **Add to Home screen** or **Bookmark**.
4. Name the shortcut `Chicago Visitations`.
5. Save it to the Home screen when offered, or use Chrome bookmarks to open it later.

## iPhone or iPad: install with Safari

Apple requires Safari for the normal Add to Home Screen flow.

1. Open the Chicago Visitations URL in Safari.
2. Tap the **Share** button (the square with the upward arrow).
3. Scroll through the actions and tap **Add to Home Screen**.
4. Change the name to `Chicago Visitations` if needed.
5. Tap **Add**.
6. Open the new icon from the Home Screen.

The icon may open as a standalone app window. If Safari does not show **Add to Home Screen**, scroll farther down in the Share sheet or confirm that the page was opened in Safari rather than an in-app browser such as a link preview inside another app.

## iPhone or iPad fallback: bookmark

If the Home Screen option is unavailable:

1. Open the site in Safari.
2. Tap **Share**.
3. Tap **Add Bookmark**.
4. Name it `Chicago Visitations` and save it to Favorites or Bookmarks.
5. Open Safari Favorites or Bookmarks whenever you need the app.

## Other browsers and desktop computers

In Chrome or Edge on a computer, look for an install icon in the address bar or choose **Install Chicago Visitations** from the browser menu. If no install option is shown, use **Bookmark this page** (`Ctrl+D` on Windows or `Command+D` on macOS).


## First launch and login

The app opens at the masjid login screen:

- **Masjid PIN**: enter the four-digit PIN provided by the masjid.
- **Masjid administrator**: open the administrator section and enter your email and PIN.
- **Markaz administrator**: use the separate Markaz admin login URL and password.

Masjid administrator login details may be remembered by the browser for session resume. Markaz admin passwords are not stored by the app. Always use **Logout** on a shared device.

## If installation does not work

Try these checks:

1. Open the direct production URL instead of a link embedded in another app.
2. Use Safari on iPhone or Chrome on Android.
3. Confirm the page is loaded over HTTPS and refresh it once.
4. Disable private/incognito browsing, then try again.
5. Use the bookmark or Home screen shortcut instructions above.
6. If the app loads but data does not appear, check your network connection and contact the application administrator.

Installing the app does not grant access. Users still need the appropriate PIN, email, or administrator password for their role.
