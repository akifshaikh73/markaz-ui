# Chicago Visitations Functional Manual

The manual is split by role:

| Manual | For | Covers |
| --- | --- | --- |
| [User Manual](functional-manual-user.md) | **Masjid Users** (masjid PIN or masjid link) — and everyone, for day-to-day work | Sign-in, masjid landing, Visitations, Full Listings and search (`*` wildcard), Student Listings, adding addresses and the duplicate check, address details and visits, routes, Quick Links, Reports, troubleshooting |
| [Admin Manual](functional-manual-admin.md) | **Masjid Admins** and **Markaz Admins** | Admin sign-in, Other Masjids, Map View, Excel export, coordinates, cross-masjid access, Markaz Admin dashboard (Masjid Management, User Management), admin troubleshooting |

## Roles at a glance

| Role | Sign-in | Access |
| --- | --- | --- |
| Masjid User | Masjid PIN at `/masjid-login`, or the masjid link (e.g. `/di`) | One masjid's listings: visitations, search, add/edit addresses, record visits, routes |
| Masjid Admin | Email and PIN under **Masjid Admin Login** at `/user-login` | Masjid User access for each assigned masjid, plus Map View, Excel export, and coordinates |
| Markaz Admin | Markaz admin password at `/admin-login` | All masjids, plus the Markaz Admin dashboard |

When behavior changes, update the manual for the affected role(s); shared screens are documented once, in the User Manual.
